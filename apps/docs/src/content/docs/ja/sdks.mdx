アプリの公式 Google Calendar SDK クライアントの接続先を Calendarpit に変更します。Calendarpit 専用の SDK は不要です。

以下の例では、カレンダーの一覧を取得し、FreeBusy を照会します。

## SDK を呼び出す前に

先にアクセストークンと SDK パッケージを用意します。

1. Calendarpit を起動します（例: `calendarpit serve`）。詳しくは[起動と設定](/ja/running/)を参照してください。
2. `https://www.googleapis.com/auth/calendar` スコープで[ローカル OAuth フロー](/ja/oauth/)を完了します。リフレッシュトークンが必要な場合は `access_type=offline` を追加します。
3. 取得したアクセストークンを、シェルの `CALENDARPIT_ACCESS_TOKEN` に設定します。トークンの有効期間は 1 時間です。
4. 各タブに記載したパッケージをプロジェクトにインストールします。Calendarpit は言語ランタイムや SDK パッケージをインストールしません。

`CALENDARPIT_ACCESS_TOKEN` は各例のコードが明示的に読み取る変数です。Google SDK の設定ではありません。

<Callout>

これらのコードは、既存のアクセストークンを渡します。Calendar API リクエストを Calendarpit に送る方法を示すためのものです。

- 認可のコールバックやトークンの自動更新は扱いません。
- トークンは `POST /oauth/token` で更新します。そのうえで、クライアントのトークンを差し替えるか、クライアントを作り直してください。

サンプルアプリと OAuth クライアントの設定全体は[アプリを接続する](/ja/connect/)を参照してください。

</Callout>

## サービス URL を設定する

エンドポイントの指定形式はライブラリごとに異なります。

- 末尾のスラッシュは表のとおりに付けてください。
- Calendarpit を別のホストやポートで実行している場合は、すべての値の `127.0.0.1:4173` を置き換えます。

| 言語                    | SDK の設定                               | 値                                        |
| ----------------------- | ---------------------------------------- | ----------------------------------------- |
| TypeScript / JavaScript | `rootUrl`                                | `http://127.0.0.1:4173/`                  |
| Python                  | `client_options.api_endpoint`            | `http://127.0.0.1:4173/calendar/v3/`      |
| Go                      | `option.WithEndpoint`                    | `http://127.0.0.1:4173/calendar/v3/`      |
| Kotlin                  | `setRootUrl` + `setServicePath`          | `http://127.0.0.1:4173/` + `calendar/v3/` |
| PHP                     | `Calendar` コンストラクターの `$rootUrl` | `http://127.0.0.1:4173/`                  |
| C# / .NET               | `BaseClientService.Initializer.BaseUri`  | `http://127.0.0.1:4173/calendar/v3/`      |

どの FreeBusy の例も、Calendarpit に `POST /calendar/v3/freeBusy` を送信します。同じクライアントで呼び出すイベントの CRUD やカレンダーリストの操作も、このローカル URL に送られます。

`calendarList` では、`list`・`get`・`insert`・`patch`・`update`・`delete`・`watch` に対応しています。ただし、[Calendar API の互換性](/ja/compatibility/)に記載した単一オーナーの制限があります。

<Callout type="warn">

SDK にほかのメソッドがあっても、対応しているのは[Calendar API の互換性](/ja/compatibility/)に記載した操作だけです。

</Callout>

## カレンダーを一覧表示して FreeBusy を照会する

<Tabs items={["TypeScript / JavaScript","Python","Go","Kotlin","PHP","C#","HTTP / curl"]}>
<Tab value="TypeScript / JavaScript" forceMount>

- **パッケージ**: `@googleapis/calendar` と `google-auth-library`
- **ランタイム**: Bun、または Node.js 22 以降で ES モジュール（`.mjs`）として実行します。
- **一体型パッケージ**: `googleapis` でも `google.calendar({ version: 'v3', auth, rootUrl })` を使えます。

```ts
import { calendar } from '@googleapis/calendar';
import { OAuth2Client } from 'google-auth-library';

const token = process.env.CALENDARPIT_ACCESS_TOKEN;
if (!token) throw new Error('Set CALENDARPIT_ACCESS_TOKEN first.');

const auth = new OAuth2Client();
auth.setCredentials({ access_token: token });
const api = calendar({
  version: 'v3',
  auth,
  rootUrl: 'http://127.0.0.1:4173/',
});

const calendars = await api.calendarList.list();
console.log(calendars.data.items);

const { data } = await api.freebusy.query({
  requestBody: {
    timeMin: '2026-10-19T00:00:00+09:00',
    timeMax: '2026-10-20T00:00:00+09:00',
    timeZone: 'Asia/Tokyo',
    items: [{ id: 'primary' }],
  },
});
console.log(data.calendars?.primary?.busy ?? []);
```

アクセストークンだけを渡したこのクライアントは、トークンを更新できません。OAuth をすべて設定する場合は、[アプリを接続する](/ja/connect/)にあるローカルの `endpoints` 設定を使ってください。

参考: [Google Calendar Node.js クライアントの実装](https://github.com/googleapis/google-api-nodejs-client/blob/main/src/apis/calendar/v3.ts)

</Tab>
<Tab value="Python" forceMount>

- **パッケージ**: `google-api-python-client`（2.x）と `google-auth`
- **ディスカバリ**: `static_discovery=True` を指定すると、インストール済みのライブラリに同梱されたディスカバリドキュメントを使います。そのため、クライアントの作成時に Google からディスカバリ情報を取得しません。
- **エンドポイント**: `api_endpoint` には `/calendar/v3/` のパスを含めます。

```python
import os

from google.oauth2.credentials import Credentials
from googleapiclient.discovery import build

credentials = Credentials(token=os.environ["CALENDARPIT_ACCESS_TOKEN"])
with build(
    "calendar",
    "v3",
    credentials=credentials,
    static_discovery=True,
    cache_discovery=False,
    client_options={
        "api_endpoint": "http://127.0.0.1:4173/calendar/v3/",
    },
) as api:
    print(api.calendarList().list().execute().get("items", []))
    result = api.freebusy().query(body={
        "timeMin": "2026-10-19T00:00:00+09:00",
        "timeMax": "2026-10-20T00:00:00+09:00",
        "timeZone": "Asia/Tokyo",
        "items": [{"id": "primary"}],
    }).execute()
    print(result["calendars"]["primary"]["busy"])
```

`Credentials` にリフレッシュトークンを渡す場合は、次のようにします。

- 登録済みのクライアント ID、クライアントシークレット、`token_uri="http://127.0.0.1:4173/oauth/token"` も指定します。
- `scopes` は省略するか、許可されたスコープを同じ順序でそのまま渡してください。

認可、userinfo、取り消しの URL は、アプリの[OAuth フロー](/ja/oauth/)で別に設定します。

参考: [同梱のディスカバリドキュメント](https://googleapis.github.io/google-api-python-client/docs/start.html#building-and-calling-a-service)、[エンドポイントの選択](https://github.com/googleapis/google-api-python-client/blob/main/googleapiclient/discovery.py)

</Tab>
<Tab value="Go" forceMount>

- **モジュール**: `google.golang.org/api` と `golang.org/x/oauth2`
- **認証情報**: トークンソースを明示的に渡します。こうすると、クライアントが Google の Application Default Credentials を探しません。

```go
package main

import (
	"context"
	"fmt"
	"log"
	"os"

	"golang.org/x/oauth2"
	"google.golang.org/api/calendar/v3"
	"google.golang.org/api/option"
)

func main() {
	token := os.Getenv("CALENDARPIT_ACCESS_TOKEN")
	if token == "" {
		log.Fatal("Set CALENDARPIT_ACCESS_TOKEN first.")
	}
	api, err := calendar.NewService(context.Background(),
		option.WithEndpoint("http://127.0.0.1:4173/calendar/v3/"),
		option.WithTokenSource(oauth2.StaticTokenSource(&oauth2.Token{
			AccessToken: token,
			TokenType:   "Bearer",
		})),
	)
	if err != nil {
		log.Fatal(err)
	}

	calendars, err := api.CalendarList.List().Do()
	if err != nil {
		log.Fatal(err)
	}
	for _, c := range calendars.Items {
		fmt.Println(c.Id)
	}

	result, err := api.Freebusy.Query(&calendar.FreeBusyRequest{
		TimeMin:  "2026-10-19T00:00:00+09:00",
		TimeMax:  "2026-10-20T00:00:00+09:00",
		TimeZone: "Asia/Tokyo",
		Items:    []*calendar.FreeBusyRequestItem{{Id: "primary"}},
	}).Do()
	if err != nil {
		log.Fatal(err)
	}
	for _, b := range result.Calendars["primary"].Busy {
		fmt.Println(b.Start, "-", b.End)
	}
}
```

`StaticTokenSource` はトークンを更新しません。SDK に OAuth を管理させる場合は、次のようにします。

1. `oauth2.Config.Endpoint.AuthURL` と `TokenURL` に Calendarpit の [OAuth エンドポイント](/ja/oauth/)を設定します。
2. `config.TokenSource(ctx, token)` を渡します。

参考: [Calendar クライアント](https://pkg.go.dev/google.golang.org/api/calendar/v3)、[WithEndpoint](https://pkg.go.dev/google.golang.org/api/option#WithEndpoint)、[OAuth の設定](https://pkg.go.dev/golang.org/x/oauth2#Config)

<Tab value="Kotlin" forceMount>

- **アーティファクト**: `com.google.apis:google-api-services-calendar`、`com.google.http-client:google-http-client`、`com.google.http-client:google-http-client-gson`
- **ランタイム**: Kotlin/JVM と JDK 11 以降。Google API Client Library for Java を Kotlin から呼び出します。

```kotlin
import com.google.api.client.http.javanet.NetHttpTransport
import com.google.api.client.json.gson.GsonFactory
import com.google.api.client.util.DateTime
import com.google.api.services.calendar.Calendar
import com.google.api.services.calendar.model.FreeBusyRequest
import com.google.api.services.calendar.model.FreeBusyRequestItem

fun main() {
    val token = System.getenv("CALENDARPIT_ACCESS_TOKEN")
    require(!token.isNullOrBlank()) { "Set CALENDARPIT_ACCESS_TOKEN first." }

    val api = Calendar.Builder(
        NetHttpTransport(),
        GsonFactory.getDefaultInstance(),
    ) { request -> request.headers.setAuthorization("Bearer $token") }
        .setRootUrl("http://127.0.0.1:4173/")
        .setServicePath("calendar/v3/")
        .setApplicationName("Calendarpit local example")
        .build()

    println(api.calendarList().list().execute().items)

    val body = FreeBusyRequest()
        .setTimeMin(DateTime("2026-10-19T00:00:00+09:00"))
        .setTimeMax(DateTime("2026-10-20T00:00:00+09:00"))
        .setTimeZone("Asia/Tokyo")
        .setItems(listOf(FreeBusyRequestItem().setId("primary")))
    val result = api.freebusy().query(body).execute()
    println(result.calendars["primary"]?.busy)
}
```

リクエストイニシャライザーのラムダで Bearer トークンのヘッダーを直接設定しています。トークンの取得と更新には[ローカル OAuth エンドポイント](/ja/oauth/)を使ってください。

`setRootUrl` を設定しても、Google の認可用ヘルパーの接続先は変わりません。

参考: [Calendar ビルダー](https://googleapis.dev/java/google-api-services-calendar/latest/com/google/api/services/calendar/Calendar.Builder.html)、[FreeBusy リクエスト](https://googleapis.dev/java/google-api-services-calendar/latest/com/google/api/services/calendar/model/FreeBusyRequest.html)

</Tab>
<Tab value="PHP" forceMount>

- **Composer パッケージ**: `google/apiclient`（2.x）
- **ランタイム**: PHP 8.1 以降。`vendor/` のあるプロジェクトディレクトリで実行します。
- **ルート URL**: `Calendar` コンストラクターの第 2 引数にオリジンを渡します。`calendar/v3/` はサービス側で付与されます。

```php
<?php

require __DIR__ . '/vendor/autoload.php';

use Google\Client;
use Google\Service\Calendar;
use Google\Service\Calendar\FreeBusyRequest;
use Google\Service\Calendar\FreeBusyRequestItem;

$token = getenv('CALENDARPIT_ACCESS_TOKEN');
if ($token === false || $token === '') {
    throw new RuntimeException('Set CALENDARPIT_ACCESS_TOKEN first.');
}

$client = new Client();
$client->setApplicationName('Calendarpit local example');
$client->setAccessToken($token);
$api = new Calendar($client, 'http://127.0.0.1:4173/');

foreach ($api->calendarList->listCalendarList()->getItems() as $calendar) {
    echo $calendar->getId(), PHP_EOL;
}

$item = new FreeBusyRequestItem();
$item->setId('primary');
$request = new FreeBusyRequest();
$request->setTimeMin('2026-10-19T00:00:00+09:00');
$request->setTimeMax('2026-10-20T00:00:00+09:00');
$request->setTimeZone('Asia/Tokyo');
$request->setItems([$item]);

$result = $api->freebusy->query($request);
foreach ($result->getCalendars()['primary']->getBusy() as $interval) {
    echo $interval->getStart(), ' - ', $interval->getEnd(), PHP_EOL;
}
```

アクセストークンだけを渡した `setAccessToken` では、トークンは更新されません。[ローカルのトークンエンドポイント](/ja/oauth/)で更新し、もう一度 `setAccessToken` を呼び出してください。

`$rootUrl` が変えるのは Calendar API リクエストの接続先だけです。`fetchAccessTokenWithAuthCode` など `Google\Client` の OAuth ヘルパーは引き続き Google に接続します。

参考: [PHP クライアントライブラリ](https://github.com/googleapis/google-api-php-client)、[Calendar サービス](https://github.com/googleapis/google-api-php-client-services/blob/main/src/Calendar.php)

<Tab value="C#" forceMount>

- **NuGet パッケージ**: `Google.Apis.Calendar.v3` と `Google.Apis.Auth`
- **プロジェクトの種類**: トップレベルステートメントを使うコンソールアプリケーション

```csharp
using System;
using System.Collections.Generic;
using Google.Apis.Auth.OAuth2;
using Google.Apis.Calendar.v3;
using Google.Apis.Calendar.v3.Data;
using Google.Apis.Services;

var token = Environment.GetEnvironmentVariable("CALENDARPIT_ACCESS_TOKEN");
if (string.IsNullOrWhiteSpace(token))
    throw new InvalidOperationException("Set CALENDARPIT_ACCESS_TOKEN first.");

using var api = new CalendarService(new BaseClientService.Initializer
{
    BaseUri = "http://127.0.0.1:4173/calendar/v3/",
    HttpClientInitializer = GoogleCredential.FromAccessToken(token),
    ApplicationName = "Calendarpit local example",
});

var calendars = await api.CalendarList.List().ExecuteAsync();
foreach (var calendar in calendars.Items)
    Console.WriteLine(calendar.Id);

var result = await api.Freebusy.Query(new FreeBusyRequest
{
    TimeMinRaw = "2026-10-19T00:00:00+09:00",
    TimeMaxRaw = "2026-10-20T00:00:00+09:00",
    TimeZone = "Asia/Tokyo",
    Items = new List<FreeBusyRequestItem>
    {
        new FreeBusyRequestItem { Id = "primary" },
    },
}).ExecuteAsync();

foreach (var interval in result.Calendars["primary"].Busy)
    Console.WriteLine($"{interval.StartRaw} - {interval.EndRaw}");
```

`FromAccessToken` はトークンを更新しません。[ローカルのトークンエンドポイント](/ja/oauth/)で更新し、認証情報を作り直してください。

`BaseUri` が変えるのは Calendar API リクエストの接続先だけです。OAuth ヘルパーの接続先は変わりません。

参考: [サービスのベース URI](https://docs.cloud.google.com/dotnet/docs/reference/Google.Apis/latest/Google.Apis.Services.BaseClientService.Initializer)、[アクセストークンによる認証情報](https://docs.cloud.google.com/dotnet/docs/reference/Google.Apis/latest/Google.Apis.Auth.OAuth2.GoogleCredential)、[FreeBusy リクエスト](https://googleapis.dev/dotnet/Google.Apis.Calendar.v3/latest/api/Google.Apis.Calendar.v3.Data.FreeBusyRequest.html)

### 期待される結果

`primary` は、認証済みのテストユーザーのプライマリカレンダーを指します。

デフォルトの Fixture の Alex の場合、この照会では busy 区間が 1 件返ります。`Asia/Tokyo` で 2026 年 10 月 19 日 `10:00` から `11:00` までの区間です。

管理画面でイベントを編集すると、次の FreeBusy の応答に反映されます。transparent のイベントとキャンセル済みのイベントは、busy 区間に含まれません。
